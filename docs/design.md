# 《流明漂航》Game Studio 设计说明

## 玩家幻想

玩家不是战斗机驾驶员，而是一台脆弱但灵活的维修无人机。爽点来自“边躲危险边抢修系统”：路线规划、手感漂移、风险收集、连锁得分和波次升级。

## 玩家动词

- 漂移移动
- 短推进穿过危险区
- 靠近信标并持续修复
- 释放脉冲推开碎片
- 收集流明补电并续连锁
- 从北侧光门撤离
- 波次结束后选择升级
- 在三档难度中选择适合自己的压力曲线

## 核心循环

1. 选择难度：练习、标准或硬核决定电量、伤害、维修和分数倍率。
2. 读图：看信标、流明、风暴和碎片的位置。
3. 补给：先捡金色流明，为修复保留电量。
4. 修复：靠近蓝色信标按 `E`，持续修复。
5. 决策：修一半离开会掉进度，继续修则可能被风暴或碎片压住。
6. 连锁：连续捡流明、修信标、撤离会提高倍率。
7. 撤离：全部信标修好后，冲进北侧光门。
8. 成长：选择升级并进入更难波次，完成 5 波后通关本轮。

## 失败和胜利

- 机体归零：失败。
- 电量归零：失败。
- 全部信标修复并进入光门：当前波次胜利。
- 第 5 波进入光门：本轮救援完成。
- 被碎片击中：扣机体、扣电量、重置连锁。
- 进入风暴：持续扣电量，强迫玩家走位。

## 难度和发行层

- 练习：电量消耗和伤害更低，维修更快，分数倍率降低。
- 标准：推荐首次游玩，完整体验核心循环。
- 硬核：电量消耗和伤害更高，额外威胁更早出现，分数倍率提高。
- 本地存档：记录最佳分数、最远波次和最佳连锁。
- 音效：WebAudio 合成短音，反馈推进、拾取、修复、受击、胜利和失败。

## 升级

- 矢量引擎：提高推力，缩短推进冷却。
- 信标织机：加快修复，提高信标得分。
- 深层电容：提高最大电量，流明回复更多。
- 棱镜脉冲：扩大脉冲范围，推开碎片更远。
- 曜盾机体：提高机体上限，降低碰撞伤害。

## UI 设计

- Phaser canvas：游戏世界、无人机、信标、流明、碎片、风暴和光门。
- DOM HUD：中文状态、目标、分数、连锁、技能状态。
- DOM overlay：中文主菜单、难度选择、音效开关、玩法说明、暂停、胜负复盘、升级选择。
- 移动端：显示触控摇杆和三个动作按钮。

## 验收标准

- 玩家打开页面能立刻知道“这是什么游戏、目标是什么、怎么操作”。
- UI 文案为中文，英文只作为副标题或技术名保留。
- 游戏支持开始、难度选择、暂停说明、继续、失败重试、胜利升级和 5 波通关。
- smoke test 覆盖推进、修复、计分、连锁、难度倍率、风暴扣电、胜利、终局、升级、暂停和失败。
- `npm test` 与 `npm run build` 通过。

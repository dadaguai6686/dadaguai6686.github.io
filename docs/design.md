# 《流明漂航》Game Studio 设计说明

## 玩家幻想

玩家不是战斗机驾驶员，而是一台脆弱但灵活的维修无人机。爽点来自“边躲危险边抢修系统”：路线规划、手感漂移、风险收集、连锁得分和波次升级。

## 玩家动词

- 漂移移动
- 短推进穿过危险区
- 跟随导航提示选择下一目标
- 靠近信标并持续修复
- 释放脉冲推开碎片
- 收集流明补电并续连锁
- 读取即时飘字和光环反馈，确认拾取、修复、受击和技能释放
- 从北侧光门撤离
- 波次结束后选择升级
- 根据结算评级复盘路线质量
- 在三档难度中选择适合自己的压力曲线
- 根据本波事件调整路线和升级优先级
- 查看当前改装等级，并比较升级前后收益

## 核心循环

1. 选择难度：练习、标准或硬核决定电量、伤害、维修和分数倍率。
2. 读图：看本波事件、信标、流明、风暴和碎片的位置。
3. 补给：先捡金色流明，为修复保留电量。
4. 修复：靠近蓝色信标按 `E`，持续修复。
5. 决策：HUD 导航会提示补流明、修信标、撤离或脱离风暴，但玩家仍要判断路线风险。
6. 连锁：连续捡流明、修信标、撤离会提高倍率。
7. 撤离：全部信标修好后，冲进北侧光门。
8. 成长：选择升级并进入更难波次，完成 5 波后通关本轮。

## 失败和胜利

- 机体归零：失败。
- 电量归零：失败。
- 全部信标修复并进入光门：当前波次胜利。
- 第 5 波进入光门：本轮救援完成。
- 被碎片击中：扣机体、扣电量、重置连锁。
- 进入风暴：持续扣电量，强迫玩家走位。

## 难度和发行层

- 练习：电量消耗和伤害更低，维修更快，分数倍率降低。
- 标准：推荐首次游玩，完整体验核心循环。
- 硬核：电量消耗和伤害更高，额外威胁更早出现，分数倍率提高。
- 波次事件：五波会依次改变战场规则，例如流明回电更多、碎片更快、风暴更强、维修更快但耗电更紧。
- 本地存档：记录最佳分数、最远波次和最佳连锁。
- 升级摘要：规则层生成当前效果和下一等级效果，HUD 与升级卡共用，避免成长反馈含糊。
- 局内导航：规则层输出当前目标，DOM HUD 显示中文提示，Phaser 画布显示导引线和目标光环。
- 结算复盘：每次胜利、通关或失败后展示分数、波次、用时、最佳连锁、流明、信标、受击和风暴停留。
- 结算评级：每局按通关状态、连锁、受击、风暴暴露、速度、流明收集和剩余电量生成 `S/A/B/C` 中文评级。
- 下一局建议：根据电量归零、机体损毁、风暴停留、拾取不足或碰撞过多给出中文指导。
- 即时反馈：画布中用短暂飘字和扩散光环标出拾取、修复、推进、脉冲、受击、撤离和失败，避免玩家只看 HUD 数字。
- 音效：WebAudio 合成短音，反馈推进、拾取、修复、受击、胜利和失败。

## 升级

- 矢量引擎：提高推力，缩短推进冷却。
- 信标织机：加快修复，提高信标得分。
- 深层电容：提高最大电量，流明回复更多。
- 棱镜脉冲：扩大脉冲范围，推开碎片更远。
- 曜盾机体：提高机体上限，降低碰撞伤害。

## UI 设计

- Phaser canvas：游戏世界、无人机、信标、流明、碎片、风暴和光门。
- Phaser feedback layer：短时文字、光环、震动和粒子用于奖励、危险和状态变化。
- DOM HUD：中文状态、目标、分数、连锁、技能状态、当前改装、当前波次事件和当前导航提示。
- DOM overlay：中文主菜单、难度选择、音效开关、玩法说明、暂停、胜负复盘、评级、下一局建议、升级选择。
- 移动端：显示触控摇杆和三个动作按钮。

## 验收标准

- 玩家打开页面能立刻知道“这是什么游戏、目标是什么、怎么操作”。
- UI 文案为中文，英文只作为副标题或技术名保留。
- 游戏支持开始、难度选择、暂停说明、继续、失败重试、胜利升级和 5 波通关。
- smoke test 覆盖推进、脉冲、拾取、修复、目标提示、升级摘要、波次事件效果、计分、连锁、难度倍率、风暴扣电、受击统计、胜利、终局原因、评级、升级、暂停和失败。
- `npm test` 与 `npm run build` 通过。
